Revenue Splitter

▶ Video
v1.9.0 · WooCommerce · MITbeta

Sales reporting with automatic per-product VAT extraction and dynamic revenue distribution among beneficiaries — authors, publishers, collaborators. Configure global defaults once, override per product, and let every beneficiary track their own net earnings through a private, key-protected portal with full transparency: sales breakdown, non-sales income, payments and outstanding balances.

All featuresFewer details
  • Per-product VAT override with global default (gross × rate ÷ (100 + rate)), aggregated per VAT rate
  • Beneficiary percentage splits with live Σ = 100% validation
  • Sales transparency: full-price / discounted (avg %) / free copies per product, pre- and post-VAT amounts
  • Non-sales ledger: custom income entries (positive or negative) and payouts, every entry with a mandatory reason, live remaining balance per period
  • Live stock column per product (read directly from WooCommerce, incl. variable products)
  • Mandatory free-copy reason at checkout, triggered only by configurable coupons — order meta visible in admin
  • Configurable sales channels — the reason coupon at checkout turns into a channel picker (store, events, wholesale…) feeding channel-based reports
  • Discount & refund transparency: undiscounted catalogue revenue (incl. native WooCommerce sale prices) and partial/full refunds netted out of every figure
  • Filter reports by product, beneficiary or title search
  • Exports: CSV (UTF-8 BOM), Excel (XLS), HTML (print → PDF) and JSON — served clean via admin_init, no admin HTML mixed in
  • Author Portal ([rs_portal]): beneficiaries log in with a personal 48-char access key (stored sha256-only) and see only their own earnings — enriched with discount stats, VAT per rate, stock, ledger history and their own CSV — no WP accounts, no IP logs, 5-attempts/15-min rate limit
  • Portal analytics: period presets & custom ranges, per-product filtering, month-over-month KPI deltas, 6/12-month trend chart
  • One-click «settle all» per period: payments recorded with reason for every beneficiary, idempotent on re-run
  • Reporting start date: reports and balances start from a clean slate
  • Full state backup & restore (JSON): atomic import with strict validation, HPOS-aware
  • WP-CLI automation: 6 commands (report, ledger-add, ledger-list, ledger-delete, balance, backup)
  • Dashboard widget with current-month snapshot, top beneficiaries, ledger summary and a monthly trend mini-chart
  • Admin polish: per-beneficiary colour coding, dark admin theme, bilingual UI (Ελληνικά / English) per user
  • HPOS-compatible — no legacy order tables touched; clean uninstall leaves nothing behind

Store Pulse

▶ Video
v1.5.0 · WooCommerce · MITbeta

A store-health dashboard and a WordPress home-screen widget for WooCommerce managers: pending and completed orders, refunds, cancellations and stock at a glance. With Revenue Splitter active, it also shows the publisher's profit and what is owed to every other beneficiary for the period.

All featuresFewer details
  • Pending orders (pending, processing, on hold), with a separate count of those older than 7 days
  • Completed orders per configurable period: unique customers, average order value and the top 10 best sellers
  • Refunds (count and amount) and cancellations, each with its own period
  • Sales by product for any period, with CSV export for Excel: filters for statuses, categories and products, choice of columns, VAT from Revenue Splitter
  • Low-stock and out-of-stock lists, including variations that manage their own stock — complete counts, lists up to 50 products
  • Revenue Splitter integration: publisher profit and amounts owed per beneficiary, read from its public API — never recalculated
  • Line items only — shipping and fees excluded, refunds netted out
  • «Quick View» widget on the WordPress dashboard with selectable cards
  • 5-minute cache, refreshed instantly when orders, Revenue Splitter data or Smart Formatter changes happen
  • Works on its own; shares the single «Noxpress» admin menu, dark theme and language choice with the other Noxpress plugins
  • HPOS-compatible, batched queries for large stores; clean uninstall leaves nothing behind

Smart Formatter

▶ Video
v1.4.0 · WooCommerce · MITbeta

Bulk formatting for WooCommerce product texts — safely. Strip stray formatting, normalize whitespace or highlight quotes, parentheses and numbers across your whole catalogue, with preview, dry run and one-click undo for every run.

All featuresFewer details
  • Targets: all published products, hand-picked products, or selected categories / tags
  • Fields: short & long description, purchase note, custom attribute values and category / tag descriptions
  • Rules: plain text (every HTML tag and attribute out, with line breaks or as one paragraph), strip inline formatting, normalize whitespace, quoted text bold / italic («» “” ""), parentheses italic, numbers bold, all text bold / italic
  • Formatting rules are safe by design: HTML tags & attributes, shortcodes, entities and <pre> / <code> blocks are never touched
  • Every rule combination yields well-formed HTML, and re-running the same rules changes nothing
  • Phrase exclusions — global and per run
  • Preview, dry run and batched apply with a progress bar — no timeouts on large catalogues
  • Undo: every run saves its backup before it changes anything; restore a whole run or selected items, or download the backup
  • Profiles for rule / field combinations, plus JSON backup & restore with strict validation
  • Bilingual UI (Ελληνικά / English), shared «Noxpress» menu and dark theme; works on its own
  • Optional: the short description becomes plain text whenever you save a product (handy when you paste from AI tools)

Free forever, and how to help

Free forever

Every noxpress plugin that has been released for free stays free and open source (MIT). If paid add-ons ever exist, they will only bring new features as separate plugins; nothing you use today will be locked.

  • No feature of a released plugin is ever moved behind a paywall
  • Easy Withdrawal, compatibility and security fixes, updates and the Noxpress hub are always free
  • No license keys, nags or ads inside the free plugins
