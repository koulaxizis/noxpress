Revenue Splitter

v1.1.2 · WooCommerce · MITbeta

Sales reporting with automatic per-product VAT extraction and dynamic revenue distribution among beneficiaries — authors, publishers, collaborators. Configure global defaults once, override per product, and track every beneficiary's net earnings across all products for any period.

  • Per-product VAT override with global default (gross × rate ÷ (100 + rate))
  • Beneficiary percentage splits with live Σ = 100% validation
  • Filter reports by product or beneficiary, CSV export (UTF-8 BOM)
  • Bilingual UI (Ελληνικά / English), per-user
  • HPOS-compatible — no legacy order tables touched

Greeklish Permalinks

v1.0.0 · WordPress · MITcoming soon

Automatically converts Greek characters to Latin in every permalink and uploaded filename — posts, pages, categories, tags, users. Full monotonic and polytonic coverage, one minimal settings page, zero bloat.

  • Complete transliteration map: monotonic, polytonic and combining diacritics
  • Separate toggle for uploaded filenames (images, PDFs)
  • Live test field with instant preview
  • Clean uninstall — nothing left behind in the database

Head & Footer Code

v1.0.0 · WordPress · MITcoming soon

Injects raw code into the <head> and just before </body>. Two textareas, nothing else — meta tags, verification codes, scripts. Secured behind the unfiltered_html capability with full nonce protection.

  • Early wp_head hook (priority 1) and late wp_footer hook (priority 99)
  • Stored raw, rendered raw — never mangles your snippets
  • Zero output when both fields are empty

Consent

v1.0.0 · WordPress · MITcoming soon

A minimalist GDPR consent banner that actually blocks third-party scripts until consent is given. One cookie, no IP addresses, no user agents, no external calls — a consent-proof log capped at 500 entries, written in vanilla JS.

  • Prior-consent script blocking via inert placeholders (preferences / analytics categories)
  • Accept-all, necessary-only and granular per-category consent
  • Re-open preferences anytime with the [nx_consent_settings] shortcode
  • Inline CSS/JS — zero extra HTTP requests, no CDN, no fingerprinting
